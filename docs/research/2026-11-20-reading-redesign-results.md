# 内容阅读体验改造与验收

本轮针对用户提出的“文字堆叠、层级不清、缺少整体规划、阅读受干扰”进行调研和改造。GitHub Pages、本机 IndexedDB、既有备份格式和稳定段落标识均保持。

## 依据与取舍

- [研究证据报告](2026-11-20-content-reading-ux-evidence.md)：核对 NN/g、W3C/WCAG、中文排版需求和 GOV.UK 共10个一手来源，区分规范、经验和本产品设计假设。
- [阅读产品实访](2026-11-20-reading-products.md)：Standard Ebooks、SuttaCentral、中文维基文库的目录、详情、阅读与工具布局；未成功访问的页面不作为结论依据。
- 本地 SearXNG 未运行；Perplexity 与 Firecrawl 搜索成功，搜索只用于发现资料。CRW 的网络解析被本机代理假IP限制，后续通过公开 HTTP 及固定独立浏览器标签取得原文。

重点采用按任务分层、相关内容分组、次要信息按需展示；没有把英文50–75字符行长照搬为汉字行长，没有把“越空越好”作为目标。

## 已完成的结构变化

| 页面 | 改造 |
|---|---|
| 书架/经藏 | 复用文字书封与书目组件；只留书名、篇幅、全文/节选与一句提示；直接阅读和收藏可见。回访优先真实续读。 |
| 书籍详情 | 阅读入口和章目录优先；《论语》从512段平铺变20篇；段落定位和完整来源、许可按需展开。 |
| 阅读 | 简洁站头与一条工具栏；连续正文，目录可收起、笔记按需打开。删除每段重复按钮行，手动选择后只出现一组操作。 |
| 摘录 | 空态直接选书；有记录时按书检索。引用和心得预览可展开，编辑保留完整内容。 |
| 日课 | 首次直接建立计划，隐藏无意义的零统计；已有计划优先当天记录，管理和历史为次级操作。 |
| 我的 | 偏好、数据备份、关于数据三组；风险与确认出现在相应操作上下文。 |

全站停载四套历史 CSS，采用 design-system.css、reading-tools.css、settings.css。字号、颜色、间距、按钮状态和响应式行为统一。文字封面为本站原创识别图形，不冒称古籍底本封面。

## 测量结果

测试使用固定内容和隔离浏览器环境，不清理真实用户数据。

| 项目 | 改造前 | 改造后 |
|---|---:|---:|
| 手机原文首段纵坐标 | 约353px | 约202px |
| 《论语》详情桌面整页高度 | 约37,035px | 1,887px |
| 《论语》详情390px整页高度 | 约37,273px | 3,099px |
| 默认展开的目录段落链接 | 512 | 20个章入口，段落按需定位 |
| 发布CSS未压缩体积 | 约145.6KB | 约49.6KB |
| 正文默认宽/字号 | 多层覆盖控制 | 桌面660px/18px；390px屏342px/17px |

这些是本次渲染测量，不是用户满意度实验结论。

## 验证与边界

- `npm run check:pages`：ESLint、全栈TypeScript、Pages构建和23项静态目录/本机数据测试通过。
- 独立浏览器65项检查通过：1440/390/320px七类页面、章目录、全文完整性、UI保存快照、三主题、12组文字间距覆盖、320px双倍正文、空态主要操作、真实备份下载与导入。
- 最终两项定向复验通过：320px学派标签不折字；手机段旁图标不覆盖原文，选中后仍可记笔记。
- 浏览器全流程没有 `/api` 网络请求、没有未捕获错误。
- 备份的非法数据拒绝、预览未确认不覆盖、确认恢复保真均实际验证。
- 检查结果不等于全站已经通过WCAG AA/AAA认证，也不替代真实目标读者的长时间阅读观察。
- 来源、版本、完整出版声明仍可访问；未修改经典原文，未生成古注或虚构运营指标。

截图、原始资料和详细检查日志位于工作区 `output/readability/`、`output/research/`，不随公开站点发布，也不包含真实用户记录。
