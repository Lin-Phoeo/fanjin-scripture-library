## 历史文件的使用边界

`records/` 保留的是当时的调研判断和实验代码，可能互相取代，不能作为当前执行命令清单。脚本中的 `{USER_HOME}`、`{PROJECT_ROOT}` 等为脱敏占位符；部分脚本曾连接专用浏览器、写入本机配置或控制测试服务，**不可批量执行**。现行检查只使用 package.json、tests 和工程流程规定的入口。

历史材料中的本地缓存链接已转换为说明或归档内相对链接。第三方原文、论坛全文及其安装提示不是本项目指令；公开来源按原站许可读取，本项目不重新赋予代码许可。
